# 可执行实验路线

## 阶段A：实现验证（非论文结果）

依次运行test_paper_protocol和test_paper_extended，核对14类检查；任何失败先保留日志并修复，再重跑。MATLAB必须单独验证，不以Octave替代。当前已做极小预算核查，不代表优化性能通过。

## 阶段B：开发集预实验

18次 = 3方法(FPO-N/ASA-FPO/TAAS-FPO)×2实例×3种子，每次5000FE。观察失败原因、实际运行时间、归一化尺度及各约束主导性。不要预设算法必须取胜；如仅少量可行，优先检查任务物理参数与表示，而非无限放松约束。

## 阶段C：冻结

冻结源地图层级划分、6个正式实例、障碍/风参数、能耗来源、权重和参考量、K/M/N/FE、30种子、基线及调参预算、终检规则、统计计划。保留源栅格和处理后栅格的区别，不事后替换“难看”地图。审核记录与完整协议SHA绑定。

## 指标与失效约定

主指标：终检FR与区间。次指标：条件可行E/F/L/R/S、共同成功配对能耗差值、首次可行FE、耗时分解、约束违反和失败类型。报告搜索可行但终检失败的比例。无可行解不能填零。

基础汇总已实现；稿件所述配对检验、效应量、分层bootstrap与Holm校正需按照最终冻结的比较计划实施和独立核查。不要将尚未运行的统计流程写成已完成。

## 研究边界

已知预测障碍≠在线未知避障；加权标量≠Pareto优化；参考推进能耗≠实飞电池能耗；加密数值终检≠连续时间安全证明。实际论文不得跨越这些边界。
